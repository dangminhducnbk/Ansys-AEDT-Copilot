# AGENTS.md

Ansys AEDT Copilot: MCP server `aedt_copilot` that cuts signal channels from Ansys AEDT / EDB boards into
simulation-ready HFSS 3D Layout designs, reviews layouts, edits layouts and builds PI-DC reports.

- To INSTALL or UPDATE on this PC: read and follow [INSTALL.md](INSTALL.md) step by step.
- To USE: after install, the MCP server's instructions and `get_guide(...)` tell you what to do.
- Contributors: see "Contributor rules" in [CLAUDE.md](CLAUDE.md) (no customer data in committed files).
